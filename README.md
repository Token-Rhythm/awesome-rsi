<a id="featured-rsi-readings"></a>
## Featured RSI Readings

- [A Survey of Self-Evolving Agents](https://arxiv.org/abs/2507.21046): The field map: what an agent evolves, when it evolves, how the update is produced, and how any of it is evaluated.
- [Darwin Gödel Machine](https://arxiv.org/abs/2505.22954): Swaps the Gödel machine's proof obligation for empirical benchmark validation, and keeps an open-ended archive instead of a single champion.
- [Huxley-Gödel Machine](https://arxiv.org/abs/2510.21614): Shows an agent's own benchmark score badly predicts how good its self-modified descendants will be, and ranks lineages by clade productivity instead.
- [Self-Adapting Language Models](https://arxiv.org/abs/2506.10943): Pushes the loop down to the weights: the model writes its own finetuning data and update directives, rewarded by post-update performance.
- [AlphaEvolve](https://arxiv.org/abs/2506.13131): Evolutionary coding agent that improved a 56-year-old matrix-multiplication bound and recovered fleet-wide compute in production.
- [Absolute Zero](https://arxiv.org/abs/2505.03335): Proposer and solver in one model, trained on self-invented tasks with a code executor as the only ground truth.
